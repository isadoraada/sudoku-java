# 🧩 Sudoku em Java

Projeto em **Java** para manipulação de Sudoku, com foco em praticar lógica, estruturas de dados e boas práticas de programação.  

## ✨ Funcionalidades

- ✅ Representação do tabuleiro 9x9
- ✅ Validação de jogadas (linha, coluna e subgrade 3x3)
- ✅ Leitura de tabuleiro inicial (fixos e espaços vazios)
- ✅ Inserção/remoção de valores 
- 🪟 Interface gráfica (Swing)

## 🧠 Como funciona (visão geral)

O Sudoku é composto por uma grade **9x9**, onde:
- cada **linha** deve conter números de **1 a 9** sem repetir;
- cada **coluna** deve conter números de **1 a 9** sem repetir;
- cada **subgrade 3x3** deve conter números de **1 a 9** sem repetir.

## 🧰 Tecnologias

- **Java** (recomendado: 11+ ou 17+)
